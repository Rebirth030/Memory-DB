# Inbox

Temporary landing zone for chat handoffs, session summaries, and cross-chat notes.

**Important:** Files here are NOT automatically permanent project truth.
They must be reviewed and filtered into the main context files using `context-update`.

## Usage

1. At the end of a productive chat, save a handoff here using `HANDOFF_TEMPLATE.md`
2. In the next chat, `context-update` will detect and process inbox files
3. Useful permanent information moves to the right context file
4. Processed inbox files are archived or deleted
